# Skill: opendesign-web

Универсальный конвейер визуального проектирования и сборки веб-интерфейсов. Работает как интеллектуальный агент-компаньон к библиотеке стилей **OpenDesign** (`design-systems/`).

## 🎯 Когда вызывать этот навык
- Владелец придумал новую идею (магазин, услугу, сервис, БАДы/травы, бота, консалтинг) и хочет красивую упаковку в вебе.
- Нужно создать **лендинг**, **интернет-витрину**, **портфолио**, **Telegram Mini App (TMA)** или **дашборд**.
- Владелец просит: «подбери дизайн», «сделай сайт в стиле OpenDesign», «упакуй проект», «создай визитку», «выкати на GitHub Pages».

## 🧠 Протокол «Арт-Директор» (Интуитивный подбор)

Когда владелец описывает любую сырую идею (например, *«магазин родиолы розовой»*, *«аренда спецтехники»*, *«сервис для юристов»*):

1. **Анализ психологии и целевой аудитории:**
   - Кто клиент? (B2B, массовый розничный покупатель, эксперт, молодежь, старшее поколение).
   - Какая ключевая эмоция должна возникнуть? (Доверие, прилив энергии, эстетика природы, премиальность, технологичность).
2. **Предложение 2–3 контрастных дизайн-концепций:**
   Назвать точные системы из каталога OpenDesign, показать цветовую палитру и аргументировать, почему этот стиль сработает.
3. **Согласование и быстрая генерация:**
   После выбора владельца — мгновенно собрать zero-dependency интерфейс, протестировать адаптивность и развернуть на хостинг.

## 🛠️ Форматы продуктов (3 режима сборки)

### Режим A: Landing / Showcase (Продающий сайт)
- **Hero-блок:** чёткий оффер, подзаголовок с выгодой, акцентные кнопки, плашка доверия.
- **Блок ценности / фич:** 3–6 карточек с иконками или визуалом, почему это работает.
- **Витрина / Каталог:** карточки товаров или услуг с ценами, бейджами («Хит», «Органика», «Тест») и описанием.
- **Социальные доказательства:** отзывы, сертификаты, кейсы, блок FAQ.
- **Финальный CTA:** большая контрастная плашка заказа с прямой ссылкой в Telegram владельца (`https://t.me/sereban_tech`).

### Режим B: Telegram Mini App (TMA / WebApp)
- Полная адаптация под экран смартфона внутри Telegram:
  ```html
  <meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no, viewport-fit=cover" />
  <script src="https://telegram.org/js/telegram-web-app.js"></script>
  ```
- Компактный каталог товаров с кнопками `+` / `-` и подсчётом суммы.
- Вызов Telegram Haptic Feedback при клике (`window.Telegram.WebApp.HapticFeedback.impactOccurred('medium')`).
- Отправка заказа прямо боту через `Telegram.WebApp.sendData(...)` или открытие диалога.

### Режим C: Quick Micro-Card (Мини-визитка)
- Одноэкранная компактная страница-визитка для быстрой вставки в соцсети и профили.

## 📐 Инженерные стандарты сборки (Zero-Dependency)

1. **Извлечение правил из OpenDesign:**
   - Читать `<open-design>/design-systems/<system>/components.html` и `system/artifacts/landing.html`.
   - Забирать корневые CSS-переменные (`:root { --bg, --surface, --accent, --border, ... }`).
   - Использовать эталонные радиусы скругления (`--radius-*`) и интервалы сетки (`--space-*`).
2. **Никаких внешних тяжелых зависимостей:**
   - Не подключать громоздкие фреймворки (Bootstrap, Tailwind CDN, React) там, где достаточно чистого CSS/JS.
   - Чистый монолитный HTML/CSS грузится за 0.1–0.2 секунды на любом смартфоне.
3. **Мобильная адаптивность:**
   - Сетка `grid-template-columns: repeat(auto-fit, minmax(...))` или брейкпоинты `@media (max-width: 768px)` и `@media (max-width: 480px)`.
   - Все интерактивные элементы — не менее 44×44px для удобного нажатия пальцем.

## 🚀 Деплой и публикация (Zero-Touch)

По умолчанию новые проекты публикуются в репозиторий GitHub Pages владельца:

1. Создать директорию под проект:
   `/home/qwerty/projects/sereban-glitch.github.io/<slug>/index.html`
2. Записать полностью рабочий самодостаточный `index.html`.
3. Закоммитить и запушить:
   ```bash
   git -C /home/qwerty/projects/sereban-glitch.github.io add <slug>/index.html
   git -C /home/qwerty/projects/sereban-glitch.github.io commit -m "feat(<slug>): add new showcase based on opendesign <style>"
   git -C /home/qwerty/projects/sereban-glitch.github.io push origin master
   ```
4. Проверить доступность:
   `curl -I -s https://sereban-glitch.github.io/<slug>/`
5. Предоставить владельцу готовую ссылку: `https://sereban-glitch.github.io/<slug>/`.
